## 💡 功能简介

TextureLink 是一款专为游戏美术开发者和 Blender 材质创作者设计的效率提升插件。
它能够一键帮你完成大量繁琐的 PBR (Physically Based Rendering) 贴图节点连接、整理、重命名、清理，甚至提供了一键打包与智能图像压缩功能，极大地提升你的工作效率。

### 核心特性

1. **一键自动连接贴图**: 提供基于贴图文件后缀名（如 `_BaseColor`、`_Normal` 等）的智能识别，自动连接到 Principled BSDF 节点的对应端口，并自动使节点排列整齐。
2. **批量匹配文件夹贴图**: 选择包含贴图的系统文件夹，一键自动匹配并链接选中的所有物体的材质。
3. **一键压缩贴图**: 针对游戏美术管线优化，智能分析材质依赖的图片，自动进行目标分辨率压缩及格式转换（支持PNG, JPEG, TARGA等），帮你轻松减小工程和打包体积。
4. **清理无用节点**: 扫描并智能删除材质中未终结到输出节点上的游离无用节点。
5. **材质重命名**: 根据最高优先级连接（如 Base Color 贴图名称）自动为匹配的材质球命名，保持工程整洁统一。面板最上方的 **UE 模式** 开关决定材质前缀：开启（默认，高亮）`MI_`，关闭 `M_`，贴图名统一 `T_`。
6. **打包并导出贴图**: 可以自动收集当前对象/整个场景关联的贴图，并将其拷贝/导出到指定的外部文件夹！

## 📥 安装指南

1. 在 Releases 页面下载最新的 `.zip` 压缩包（或者点击 Code -> Download ZIP）。请**不要解压**该 ZIP 文件。
2. 打开 Blender，前往 **编辑 (Edit)** -> **偏好设置 (Preferences)** -> **插件 (Add-ons)**。
3. 点击顶部的 **安装 (Install)** 按钮。
4. 在弹出的文件浏览器中，找到你刚刚下载的 `.zip` 压缩包，选中并点击 **安装插件 (Install Add-on)**。
5. 在插件过滤搜索框中输入 "TextureLink"，勾选插件左侧的方框以启用它。

## 🎮 如何使用

1. 打开 Blender 中的任一 **着色器编辑器 (Shader Editor)** 视图（或者节点编辑器视图）。
2. 在视图右侧，按快捷键 `N` 呼出侧边栏 (Sidebar)。
3. 点击 **PBR Tool** 标签页，即可看到所有的功能面板！
4. **一键连接演示**:
   - 将贴图拖入 Shader Editor 中。
   - 选中包含贴图节点的那个材质对象。
   - 点击面板中的“自动连接贴图”，见证奇迹！
